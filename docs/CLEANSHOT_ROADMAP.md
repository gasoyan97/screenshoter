# Дорожная карта: фичи в стиле CleanShot X

Ориентир: [CleanShot X](https://cleanshot.com/) — «50+ фич в одном приложении» для скриншотов и записи экрана на Mac.

## Уже есть в ScreenShoter

| Фича CleanShot | Статус в ScreenShoter |
|----------------|------------------------|
| **Захват экрана** — вся область, окно, выбранная область | ✅ Режимы full / window / region |
| **Аннотации** — стрелки, подсветка, размытие | ✅ Arrow, highlight, blur в AnnotationView |
| **Облако и ссылка** — загрузка и публичная ссылка | ✅ WebDAV + публичная ссылка (Яндекс и др.) |
| **Кастомные обои/фон** — обои для скриншота | ✅ Обои рабочего стола или свой файл, паддинг S–XXL |
| **Горячие клавиши** | ✅ Два шортката (с редактированием / без) |
| **Меню в трее** | ✅ Menu bar, быстрый доступ |
| **История загрузок** | ✅ История с ссылками |
| **Настройки** — формат, папка, облако, автозапуск | ✅ |

## В работе / планируется

| Фича | Описание | Статус |
|------|----------|--------|
| **Таймер перед съёмкой** | Сделать скриншот через 3 / 5 / 10 сек | ✅ Готово (меню «С таймером») |
| **Копировать в буфер** | Копировать скриншот (с аннотациями) в буфер обмена | ✅ Готово (кнопка в окне аннотаций) |
| **Уменьшать Retina** | Опция «2x → 1x» для меньшего размера файла | ✅ Готово (Настройки → Сохранение) |
| **Быстрый оверлей** | После съёмки — панель «Сохранить / Копировать / Загрузить» без полного окна аннотаций | 📋 Планируется |
| **Скрывать иконки рабочего стола** | Временно скрывать иконки на рабочем столе при съёмке | 📋 Планируется |
| **Закреплённые скриншоты** | Окно поверх всех окон (pin) для справки | 📋 Планируется |

## Долгосрочно (как у CleanShot)

| Фича | Сложность | Заметки |
|------|-----------|--------|
| **Прокручиваемый захват** | Высокая | Захват контента с прокруткой (чаты, код) |
| **Запись экрана** | Высокая | Видео и/или GIF, рекордер |
| **OCR / распознавание текста** | Средняя | Копировать текст с изображения (Vision / on-device) |
| **Режим прицела (crosshair)** | Средняя | При выборе области показывать прицел для выравнивания |
| **Готовые фоны** | Низкая | Набор фонов «как у CleanShot» (градиенты, текстуры) |
