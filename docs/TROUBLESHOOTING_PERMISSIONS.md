# Разрешения запрашиваются снова после обновления

## Проблема

После обновления приложения через Sparkle (или вручную) macOS снова просит разрешения: «Запись экрана», «Уведомления» — хотя пользователь их уже выдавал.

## Причина

macOS привязывает разрешения к **подписи приложения**. Когда приложение собрано с ad-hoc подписью (`codesign -s -`), каждая новая сборка получает уникальную подпись. После обновления macOS считает это другим приложением и сбрасывает разрешения.

## Решение

Собирать приложение с **Developer ID** подписью. Тогда все версии имеют одинаковую подпись (Team ID) — macOS распознаёт обновление как то же самое приложение, разрешения сохраняются.

### Что сделать

1. Оформить **Apple Developer Program** ($99/год).
2. Получить сертификат **Developer ID Application**.
3. Добавить секреты в GitHub (см. [BUILD_DMG.md](BUILD_DMG.md)):
   - `BUILD_CERTIFICATE_BASE64`
   - `P12_PASSWORD`
   - `KEYCHAIN_PASSWORD`
   - `APPLE_ID`, `APPLE_APP_SPECIFIC_PASSWORD`, `TEAM_ID` (для нотаризации)
4. При следующих релизах сборка будет подписываться Developer ID — пользователи не будут видеть повторные запросы разрешений после обновления.

### Альтернатива

Без Developer ID — это ожидаемое поведение. Пользователь может один раз заново выдать разрешения в Системных настройках → Конфиденциальность и безопасность после обновления.
